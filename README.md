# DownedRP

Standalone knockdown, self-treatment and assisted-walk system for Project Zomboid B42 multiplayer.

Based on [Down But Not Out](https://steamcommunity.com/sharedfiles/filedetails/?id=3774055538) by phasmoware (Workshop ID 3774055538). Original code licensed under MIT. See [LICENSE_DBNO.txt](LICENSE_DBNO.txt).

## Features

- **Health-threshold knockdowns** with crawl, bleedout timer and hold-health modes
- **Teammate "Help Up" revive** with configurable duration and restored health
- **Knockdown strike counter**: after N knockdowns in a window the next one is fatal
- **Self-treatment**: downed players may treat their own wounds if their First Aid level allows it, then stand up
- **Assisted walk**: after a revive the rescued player follows the rescuer at reduced speed
- **MoodleFramework moodle** showing recent knockdowns

## Requirements

- [MoodleFramework](https://steamcommunity.com/sharedfiles/filedetails/?id=2864977286)
- Project Zomboid Build 42+

## Installation

1. Subscribe to the mod on Steam Workshop
2. Enable the mod in the Project Zomboid mod menu
3. Ensure MoodleFramework is also enabled and loaded before DownedRP

## Configuration

All settings can be configured via Sandbox Options under the **DRPMain** and **DRPAssist** pages.
